# Binance Futures Web Backtester

一个可以部署为独立网页的币安 USDⓈ-M 合约回测原型。使用 Streamlit 提供网页界面。

## 不需要在自己的电脑安装 Python（云端部署方式）
你可以通过 GitHub + Streamlit Community Cloud 部署：
1. 注册/登录 GitHub，创建一个新的仓库。
2. 将本项目中的 `app.py`、`requirements.txt` 上传到仓库根目录。
3. 登录 https://share.streamlit.io/ 并连接 GitHub。
4. 选择仓库、分支和主文件 `app.py`，点击 Deploy。
5. 部署成功后会得到一个网页地址。运行时由云端提供 Python 环境。

提示：云平台可用性、访问限制和免费额度可能变化。部署环境需要能访问币安公开 API。

## 本地运行（可选）
需要 Python 3.11 或 3.12：
```bash
pip install -r requirements.txt
streamlit run app.py
```
浏览器打开 Streamlit 提供的本地地址。

## 使用
- 输入交易对，例如 `BTCUSDT`、`ETHUSDT`
- 选择 K 线周期和日期范围
- 调整双均线参数、初始资金、杠杆、手续费和滑点
- 点击“运行回测”
- 查看净值、回撤、均线图，下载 CSV

日期以 UTC 解释。当前结束日期控件包含所选日期当天的数据。

## 当前版本的重要限制
这是研究原型，不是生产级撮合引擎：
- 默认示例策略是双均线多空切换。
- 成本模型为近似模型；没有逐笔成交、订单簿、排队位置、延迟、部分成交和市场冲击。
- 资金费率按附近 K 线持仓简化计算，不应视为精确账单复现。
- 没有维持保证金、风险限额、强平、自动减仓（ADL）模型。高杠杆结果可能严重失真。
- 下载数据和运行速度受币安 API、网络和云端资源限制。
- 不需要 API Key；不要把 API Secret 上传到 GitHub。
- 不提供投资建议，也不保证回测收益能在实盘复现。
